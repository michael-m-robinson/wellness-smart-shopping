Install from the disk image

The app is self-contained. Nothing needs to sit beside it.

  1. Build the image, then open it
    Expect a window with the app, an Applications shortcut and a Read Me.
    cd app && ./make_dmg.sh open "dist/Wellness Smart Shopping.dmg"
  2. Drag the app onto the Applications shortcut
    Copies in a second or two. Then eject the image.
  3. Open it from Applications (or Launchpad)
    Launches with no Gatekeeper warning — it is ad-hoc signed.
  4. Check Launchpad shows exactly one
    One Wellness Smart Shopping. Two means a stale copy survived.
02

Your daily targets

First run asks for the few details that size the shopping list to you.

  1. Press Scan with Claude…, then Start Control Panel
    Progress ticks, then the panel opens in your browser.
  2. The targets form opens by itself
    Only on a first run, when no profile is saved yet.
  3. Enter height, weight, age, sex and activity
    The target updates as you type, no Save needed.
  4. Switch activity from Sedentary to Very active
    Calories and protein both rise — training raises protein need, not just energy.
  5. Switch goal between Maintenance, Cutting and Build Muscle
    Cutting lands below maintenance, Build Muscle above.
  6. Clear the age field
    Falls back to a size-only estimate and says so, rather than breaking.
  7. Press Save targets, then reload the page
    The card keeps your numbers; the form no longer opens on its own.
  8. Press Edit on the targets card
    Reopens with your saved values in the fields.

  6. Pick a shopping list message, or write your own

04

Scan with Claude

needs the extension

The heart of it: Claude reads deals off a store page you are signed in to.

  1. Press Scan with Claude in the panel
    A store picker, each store marked scanned or not scanned yet.
  2. Pick ShopRite
    Links to its coupon list and weekly ad — labelled differently, not twice the same.
  3. Press Copy on the instruction
    Button confirms. The path in it is where your scan must be saved.
  4. Open the store, sign in, and give Claude that instruction
    Claude scrolls the whole list and saves one offer per line.
  5. Leave the panel waiting
    It notices within a few seconds — no button to press.
  6. Read the result
    “N deals found. Import it now?” If nothing matched your staples it says so plainly instead of writing an empty file.
  7. Press Not now
    Tells you exactly where the file is waiting. Declining loses nothing.
  8. Scan again and press Import deals now
    Opens the app, reveals the file in Finder, path on your clipboard.
  9. Try it without a scan — try the sample instead
    Ten matches, including a per-pound price converted to a per-package one.
    python3 crawl.py --harvest shoprite=examples/sample-scan.txt --report
05

The deals are sound

A wrong match quietly corrupts your budget, so these are worth checking.

  1. Look at the reported basis for each deal
    Per-pound converted to per-package, “2 for $5” to a unit price, limits carried through.
  2. Check what was not matched
    Junk is rejected: “Peanut Butter Cups” and “Cinnamon Toast Crunch” are not peanut butter and cinnamon.
  3. Validate the XML against the catalog
    Prints clean. Unknown item IDs are silently dropped by the app, so this matters.
    python3 -c "import sys;sys.path.insert(0,'.');\ from dealcrawler.xmlout import validate;\ print(validate(open('out/shoprite-sales-2026-09-20.xml').read()) or 'clean')"
06

The desktop app

Planning and PDFs live here; scanning lives in the panel.

  1. Read the button on the main window
    It says Scan with Claude… — never “Coupons (1)…”. The old coupon finder is deleted, not hidden.
  2. Open its panel
    Four controls and no list of entry boxes: Start Control Panel, Import Sales XML, Clear, Close.
  3. Choose Import Sales XML… and pick your file
    Offers the deals for confirmation, then applies them.
  4. Close the panel, reopen it
    Your imported deals survive. Closing must never wipe them.
  5. Click into the browser while the panel is open
    The window stays put; it does not vanish when the app loses focus.
  6. Create the PDFs
    Shopping list, recipes and daily meals, priced around your imported deals.
  7. Quit the app
    The control panel stops with it — the app started it, so the app stops it.
    pgrep -fl panel.py # expect nothing
  8. Run its own self-test
    Ends SELF_TEST_OK, including XML_IMPORT_OK.
    "/Applications/Wellness Smart Shopping.app/Contents/MacOS/SmartShoppingList" \ --self-test /tmp/a.pdf /tmp/b.pdf /tmp/c.pdf
07

Where your files live

An installed app is read-only and signed, so nothing may be written inside it.

  1. Look in Application Support
    config.json, branding.json, profile.json, harvest/, out/, themes/.
    open ~/Library/Application\ Support/Wellness\ Smart\ Shopping
  2. Confirm nothing was written inside the app
    No output. A write in there would break the signature.
    find "/Applications/Wellness Smart Shopping.app" \ -name "*.pyc" -o -name "config.json" -o -name "__pycache__"
  3. Re-verify the signature after a full session
    Silence means valid.
    codesign --verify --deep --strict "/Applications/Wellness Smart Shopping.app"
  4. Confirm it never phones home
    Passes. The crawler makes no network requests at all; deals come only from a scan you ran.
    python3 test_crawler.py 2>&1 | tail -3 # 116 tests
08

Off again, cleanly

do last

Anything you give away should come off without leaving a mess.

  1. Check first, change nothing
    Reports every copy it can find and creates nothing.
    python3 installer.py --check
  2. Uninstall
    App, preferences, caches, WebKit and HTTPStorages all go. Your shopping data is asked about separately.
    python3 installer.py --uninstall
  3. Check Launchpad and Spotlight
    No ghost entry — removals deregister from LaunchServices, not just delete files.
If a check fails, note the row number and what you saw instead. The gap between “what to do” and “what you should see” is usually enough to find it.
